# Month 3: Week 10: Redirecting the example code to my Ogbia Settlements Data

- `my_explore.py` – Explores and inspects the settlement dataset.
- `my_extract_settlments_centroid.py` – Extracts settlement attributes and centroid coordinates into a CSV. This is to enable me carry out my_points.py exercise.
- `my_points.py` – Reconstructs settlement centroid points from the CSV and exports them as a GeoPackage.
- `my_join.py` – Joins the extracted settlement data back to the original dataset.
- `my_map.py` – Maps Ogbia wards, settlement polygons, and centroid points.


## Final Output from the challenge
- `my_ogbia_settlement_map.png` – Final map showing Ogbia wards, settlement polygons, and settlement centroid points.
